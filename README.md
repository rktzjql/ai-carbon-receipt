# Gemini Carbon Receipt

Chrome Manifest V3 확장프로그램. Gemini에서 이미지 생성에 사용한 텍스트를 별도 Gemini API 요청으로 실행하고 **그 API 응답의 실제 `usageMetadata`**를 표시합니다. 웹사이트 내부 토큰 측정기가 아닙니다. Gemini 화면 아래 영수증에 별도 API 실측 토큰과 웹 생성 이미지 수를 구분해 표시합니다. 전력은 사용자 지정 임시 가정값 `0.001921 Wh/token`으로 추정하며, 탄소는 사용자 제공 미국 계수 `0.341 kg CO₂eq/kWh`로 추정하며, 물은 환산계수 미설정으로 `미산정`을 표시합니다.

## 모델 및 검증 상태

- 요청 모델 ID: `gemini-3.1-flash-lite-image` (사용자가 지정한 Nano Banana 2 Lite)
- `generationConfig.responseModalities`: `TEXT`, `IMAGE`
- `generationConfig.imageConfig.imageSize`: `1K`
- 모델 ID나 별칭의 실제 제공 여부는 **미검증**입니다. 다른 모델로 자동 대체하지 않습니다. 패널의 **API 모델 접근 확인**은 `GET /v1beta/models/{model}`을 실행합니다. 조회 성공만으로 이미지 생성·1K 지원이 검증되지는 않습니다. 실제 이미지 생성 테스트까지 필요합니다.
- 실제 API 키가 없어 유료 이미지 생성, 실제 토큰 응답, 모델 접근 권한은 검증하지 않았습니다.
- 로그인한 Gemini 실서비스의 DOM, 언어별 모델 메뉴, 실제 프롬프트 제출 감지는 수동 검증이 필요합니다. 선택자가 일치하지 않으면 자동 호출하지 않습니다.

공식 자료:

- [Gemini 이미지 생성 가이드](https://ai.google.dev/gemini-api/docs/image-generation)
- [GenerateContent REST / UsageMetadata](https://ai.google.dev/api/generate-content)
- [Models.get](https://ai.google.dev/api/models#method:-models.get)
- [Google 공식 Python SDK 타입 정의](https://github.com/googleapis/python-genai/blob/main/google/genai/types.py)

이 개발 환경에서는 `ai.google.dev`가 네트워크 프록시의 403 응답으로 차단되어 문서 본문을 직접 확인하지 못했습니다. 접근 가능한 공식 SDK에서 ImageConfig의 `1K`, response modalities, usage metadata 필드를 교차 확인했습니다. 최신 모델 지원 여부는 위 공식 문서와 본인 키로 확인해야 합니다.

## 설치

1. 이 프로젝트 폴더 전체를 로컬 컴퓨터에 다운로드합니다. `manifest.json`이 있는 폴더가 확장프로그램 루트입니다.
2. Chrome에서 `chrome://extensions`를 열고 **개발자 모드**를 켭니다.
3. **압축해제된 확장 프로그램을 로드합니다**를 눌러 이 폴더를 선택합니다. npm 설치나 빌드는 필요하지 않습니다.
4. 확장프로그램 아이콘 → **설정 / API 키**에서 본인의 Gemini API 키를 입력합니다.
5. **큰 화면으로 열기**로 패널을 탭에 열어 둡니다. 팝업을 닫아도 이미 시작한 요청의 결과는 세션 기록에 남지만, 탭이 진행 상태를 보기 편합니다.
6. 기존 Gemini 탭을 새로고침합니다. 확장프로그램을 재로드한 뒤에도 Gemini 탭을 새로고침하세요.

Chrome 102 이상을 요구합니다. API 키의 접근 제한 세션 저장에 필요한 최소 버전입니다. v0.1.1에서 최소 버전을 120에서 102로 낮추고, 최신 AbortSignal.timeout 대신 AbortController 타이머를 사용하도록 변경했습니다. Chrome 102–119 실기기 동작은 미검증이며 실제 사용에는 최신 Chrome을 권장합니다.

## 선택: API 단독 테스트 (자동 영수증에는 불필요)

1. 패널에서 **API 모델 접근 확인**을 누릅니다. 404는 모델 ID/제공 여부, 400·403은 키·권한·요청 오류, 429는 할당량·요금 상태를 확인합니다. 오류 원문이 패널에 표시됩니다.
2. 이미지 생성 프롬프트를 입력하고 별도 요청·추가 요금 동의에 체크합니다.
3. **단독 API 테스트 실행**을 한 번 누릅니다.
4. 결과가 `이미지 생성 성공`인지, 이미지 수가 1 이상인지 확인합니다. TEXT만 반환되면 `응답 수신 · 이미지 없음`으로 구분합니다.
5. 입력·출력·사고·전체 토큰과 원본 `usageMetadata`를 비교합니다. 누락 필드는 `미제공`이며 0으로 추정하지 않습니다. 전체 토큰은 합산하지 않고 API 값을 그대로 표시합니다.
6. 이미지 모달리티 세부 정보는 API가 `promptTokensDetails` 또는 `candidatesTokensDetails`를 제공했을 때만 표시됩니다. 생성 이미지 바이트는 수신 후 폐기하며 미리보기/다운로드는 제공하지 않습니다.

## 이미지 응답을 기다리는 새 흐름

프롬프트를 다시 입력할 필요 없이 제출한 텍스트를 기억합니다. 입력창이 비워진 뒤 새 model-response와 같은 대화 턴의 user-query 텍스트가 제출 프롬프트와 일치하는지 확인합니다. 해당 응답의 생성 이미지가 로딩되면 별도 유료 API를 한 번 호출합니다. 추적·자동 전송 동의·모델 확인·첨부 없음 조건이 필요합니다. 웹 모델을 읽지 못할 때는 설정의 지정 API 모델 사용 동의로 모델 확인을 대신할 수 있습니다. 이미지 확인 전에는 API를 호출하지 않습니다.

각 Gemini 이미지 응답 아래 영수증에는 API 상태, 별도 API 응답의 실제 입력·출력·사고·전체 토큰, Gemini 웹 생성 이미지 수와 API 응답 이미지 수를 구분해 표시합니다. 전력은 별도 API의 실제 `totalTokenCount × 0.001921 Wh/token`으로 계산합니다. 이 값은 사용자 지정 임시 가정이며, 공개 출처 및 Gemini 이미지 생성에 대한 타당성은 미검증입니다. 1,513토큰은 약 2.906 Wh입니다. 전체 토큰이 누락되면 합산으로 보충하지 않고 미산정으로 표시합니다. 웹사이트 이미지 생성 전력이나 두 요청의 합계가 아닙니다. 탄소는 `전력(Wh) / 1000 × 0.341 kg CO₂eq/kWh × 1000 g/kg`으로 계산합니다. 1,513토큰의 탄소 추정치는 약 0.991 g CO₂eq입니다. 미국 배출계수는 사용자가 제공한 값으로, 출처·기준연도·실제 Gemini 서버 지역은 확인되지 않았습니다. 전체 토큰이 없으면 탄소도 미산정이며, 물 환산계수는 설정하지 않아 미산정입니다.

제출별로 최대 20개 감지를 유지하고, 각각 대응하는 응답 아래에 영수증을 표시합니다. 새 대화의 /app → /app/대화ID 주소 변경은 프롬프트 일치를 확인한 경우 처리합니다. 다른 기존 대화로 이동하거나 응답 연결이 불명확하면 자동 호출하지 않습니다. 이미지 대기는 3분이며 개수는 처음 로딩을 확인한 시점의 수입니다. 페이지 새로고침 시 대기 상태는 복원하지 않습니다. API 요청 중에도 영수증이 표시되고 완료 후 사용량으로 갱신됩니다. 닫은 영수증은 다시 나타나지 않습니다.

## 이후: Gemini 웹사이트 연결

1. 확장프로그램의 **설정 / API 키**에서 API 키를 저장합니다.
2. **자동 이미지 영수증 설정**에서 감지와 추가 요금이 발생하는 자동 API 전송 동의를 켭니다.
3. 웹 모델 확인 없이 지정 API 모델을 사용할 경우 세 번째 동의도 켭니다. 웹사이트와 같은 모델이라는 보장은 아닙니다.
4. 기존 Gemini 탭을 새로고침하고 Gemini 입력창에 평소처럼 이미지 프롬프트를 제출합니다. 별도 프롬프트 입력은 필요 없습니다.
5. 생성 이미지가 로딩되면 해당 응답 아래 영수증이 나타나고, API 요청 상태가 토큰·전력·탄소 추정치로 갱신됩니다. 물은 계수가 없어 미산정입니다.
6. API 키 누락·모델 접근 오류·자동 호출 보류는 영수증이나 패널에서 확인합니다. 실패한 요청은 자동 재시도하지 않습니다.

DOM 감지는 비공식 휴리스틱입니다. 입력창이 비워진 사실은 서버의 생성 접수를 증명하지 않습니다. 웹사이트의 UI 변경·파일 첨부 표시 변경으로 누락이나 오탐이 생길 수 있으므로 처음에는 자동 동의를 끄고 수동 확인으로 검증하세요. 실제 모델 ID나 웹사이트의 이미지 해상도를 내부 API에서 추출하지 않습니다. 웹사이트 선택 이름의 확인과 별도 API 모델의 동일성은 보장하지 않습니다.

확장프로그램은 제출 이벤트를 관찰하며 `preventDefault`, fetch 가로채기, 페이지 내부 코드 실행을 하지 않으며, 응답 아래에 격리된 스타일의 영수증 DOM을 추가합니다. 텍스트 프롬프트만 복제합니다. 대화 이력·첨부 파일·시스템 프롬프트·웹사이트의 내부 설정은 포함하지 않으므로 결과 이미지와 사용량은 달라질 수 있습니다.

## 중복 방지와 저장

- 한 입력 제출의 Enter/click/submit은 content script에서 하나의 이벤트 ID로 묶습니다. 입력 변경 후 같은 문구를 다시 제출하면 별도 요청입니다.
- worker는 탭 ID + 이벤트 ID를 세션에 저장하고 요청 전 `running` 상태를 저장합니다. 기록을 지워도 중복 방지 표식은 유지합니다.
- API 생성과 수동 확인은 직렬 처리합니다. 실패·시간 초과·worker 종료 시 자동 재시도하지 않습니다. 요청이 서버에 전달된 후 응답만 유실되었을 수 있으므로 수동 재요청은 추가 과금될 수 있습니다.
- Chrome이 worker를 종료하면 `요청 중 / 결과 미확정` 기록이 남을 수 있습니다. 클라이언트 타임아웃은 120초이지만 Chrome의 worker 수명 제한이 더 일찍 적용될 수 있습니다.
- 최근 최대 20개 기록(프롬프트, usage, 응답 요약)을 세션에 보관합니다. 구버전 Chrome의 1 MB 세션 한도를 고려하여 기록이 약 350 KB를 넘으면 오래된 기록부터 제거합니다. 세션당 중복 표식 한도는 2,000개입니다. 브라우저 재시작/확장 재로드 시 키·기록·표식이 사라집니다.
- API 키는 `chrome.storage.session`의 `TRUSTED_CONTEXTS`로 제한합니다. 페이지와 content script에는 키를 반환하지 않습니다. 키는 worker가 `x-goog-api-key` 헤더로 공식 API 호스트에만 전송합니다. 영구 저장되는 `storage.local`에는 추적·동의 설정만 있습니다.
- 키 삭제는 이후 요청에 적용됩니다. 이미 시작된 API 요청을 취소하지 않습니다. 키를 README나 코드·Git에 넣지 마세요.

## 개발 검증

Node.js 22 이상, 외부 npm 의존성 없음:

```sh
cd /workspace/ai-carbon-receipt
npm run check
npm test
# Chromium이 설치된 Linux 환경에서 선택적으로 실행
node scripts/browser-smoke.mjs
```

브라우저 스모크 테스트는 임시 프로필과 로컬 디버깅 포트 9223을 사용하며 Linux 컨테이너 호환을 위해 `--no-sandbox`로 실행합니다. 실제 개인 Chrome 프로필에서는 이 옵션을 사용하지 마세요. 다른 Chromium 경로는 `CHROMIUM_PATH`로 지정합니다. 테스트는 API 요청을 하지 않습니다.

검증 결과: 정적 검사 통과, 자동 테스트 16개 통과. 실제 Chromium 스모크 검사는 이 환경의 관리자 정책(`Loading of unpacked extensions is disabled by the administrator.`)으로 확장 로드가 차단되었습니다. 이 정책을 우회하지 않았으며 브라우저 UI 실행 성공을 주장하지 않습니다. 확장 설치가 허용된 로컬 Chrome에서 위 수동 테스트를 진행하세요.

모의 테스트의 숫자는 테스트 fixture이며 실제 UI의 측정값이나 실제 API 성공 증거가 아닙니다.

## 사용자가 확인해야 할 테스트

- [ ] API 모델 조회 성공, 정확한 모델 ID와 계정 권한 확인
- [ ] 실제 1K 이미지 생성 성공 및 원본 usageMetadata와 토큰 표시 일치
- [ ] 잘못된 키, 404 모델, 할당량 오류, 안전 필터, 이미지 없는 응답 표시
- [ ] 지정 API 모델 사용 동의 OFF + 웹 모델 불명확 시 자동 호출 0회
- [ ] 일반 텍스트 채팅과 이미지에 관한 설명 질문에서 자동 호출 0회
- [ ] 추적 OFF 또는 자동 동의 OFF에서 자동 호출 0회
- [ ] 이미지 요청 1회 제출 시 API 호출 1회, Enter/click 중복·확인 버튼 재클릭에도 1회
- [ ] 한국어 IME 조합 확정 Enter와 Shift+Enter 줄바꿈에서 호출하지 않음
- [ ] 같은 문구를 실제로 다시 입력·제출하면 별도 기록 1개 생성
- [ ] 콘텐츠 스크립트 실행 컨텍스트에서 `chrome.storage.session`에 키 접근 불가
- [ ] 브라우저 재시작 후 키가 사라지고, 진행 중 worker 중단 시 자동 재시도 없음
- [ ] 웹사이트 입력·전송·이미지 생성 기능이 정상 유지됨

소스 코드는 GitHub에서 내려받아 압축해제 확장프로그램으로 설치할 수 있습니다. Chrome 웹 스토어에는 배포하지 않았습니다.
